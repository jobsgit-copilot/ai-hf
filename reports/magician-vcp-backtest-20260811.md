## 一、回测方法

- **事件定义**：对每个评估日×标的运行 VCP 检测（窗口 60 日、收缩≥2 次、深度逐次递减、末次 ≤ 首次 70%，与 `vcp_detector.py` 一致），共检出 **8376 个 VCP 事件**。
- **买入规则**：`breakout` 模式——收盘价突破中枢点（pivot）当日收盘价成交，且收盘价不超过中枢点 +15%（追高过滤）；同一标的两次建仓间隔 ≥ 80 个交易日（同一基底只计一次）。
- **止损**：中枢点下方 7%/8%/10% 与基底最低点取价格更高者（更近的止损）。
- **目标**：按盈亏比 RR=2/3 设定固定目标价。
- **度量**：从突破次日起（T+1），60 个交易日内先触止损/目标即离场，否则按末日收盘；另计算"先达 +20% 再触发止损"比率（Minervini 检验口径）。
- **参数网格**：止损 7/8/10% × RR 2/3 × 收缩次数 2/3 × RS 分位 0/70/90 × 是否要求第二阶段，共 72 组。

**已知局限（结论需谨慎使用）**
- 收盘价成交近似，未模拟次日开盘滑点、涨跌停无法成交/卖出。
- 缓存为当前在市股票，存在幸存者偏差（退市股缺失）。
- 缓存无成交量字段，无法验证"量能萎缩"这一原著关键确认条件。
- 月度采样会错过部分精确突破日，可能放大"追高"误差。
- 固定目标价/固定持有期是简化模型，未模拟"强势卖出/止损上移"等动态管理。

## 四、参数层面的发现

1. **止损 7% 优于 8%/10%**（期望角度）：更紧的止损减小均亏；但 10% 止损胜率更高（40%+）。两者相差不大，7% 更适合纪律型执行。
2. **RR=3 目标优于 RR=2**：右尾收益更大；RR=2 的胜率更高但期望更低。
3. **收缩 ≥ 3 次优于 ≥ 2 次**：期望约 0.94% vs 0.59%，且样本减半；≥3 次的基底结构更可靠。
4. **RS≥70 有轻微帮助、样本变小**；**RS≥90 全部为负期望**（-0.2% ~ -3.7%）。高 RS 标的常处行情后段，追突破反而不利。→ 不建议把 RS≥90 作为硬性否决。
5. **阶段 2 过滤**：要求阶段 2 会减少约 40% 交易，期望与不要求时相近（略低但更符合方法论）；建议保留（一致性优先）。
6. **"先达 +20%"比率**：全期 32-35%，前期 44-47%，后期 29-32% —— 弱势市大赢家明显减少。

## 五、参数校准结论（v1 推荐默认）

| 参数 | 原默认（设计文档） | 校准后建议 |
|---|---|---|
| 收缩次数 | ≥ 2 | **优先 ≥ 3**（≥2 仅进观察池） |
| 止损宽度 | 中枢点下方 7-10% | **7%（激进）/ 10%（稳健）**，硬上限 10% |
| 盈亏比 RR | ≥ 2 | 硬下限 ≥ 2；**计划目标按 ≥ 3**（配合强势卖出） |
| RS | ≥ 70（最好 90） | **不作一票否决**；≥70 加分；不设 ≥90 硬门槛 |
| 第二阶段 | 必须 | 保留 |
| 追高限制 | 无 | **新增：突破后收盘距中枢点 ≤ 15%**，超过不追 |
| 大盘环境 | 无 | **新增：沪深300 站上 200 日线才启用**；弱势市减仓/空仓 |

> 以上为单一样本（2020-2026、后复权、月度采样）的 v1 结论，样本内收益与实盘差异可能很大；建议后续用日度采样、含成交量确认的样本复核，并在实盘小仓验证。
