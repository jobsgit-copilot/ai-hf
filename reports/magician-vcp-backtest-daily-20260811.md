# 股票魔法师 VCP 策略日度评估 + 带量复核报告（Phase 4 复核）

> 日期：2026-08-11
> 数据：`data/magician/live_cache.pkl`（xtquant 前复权日线，**含成交量**，2018-01 ~ 2026-08，5209 只）
> 样本：2020-01 ~ 2026-08；标的池 3120 只（近 60 日均成交额 ≥ 1 亿元）；**评估日 1601 个（每个交易日）**
> 工具：`tools/magician_backtest.py`（`cache` 建缓存 + `sweep --step 1 --brv --dry --workers 8`）

---

## 一、复核目的与方法

月度回测（`magician-vcp-backtest-20260811.md`）留下两个未验证问题，本报告用日度评估与带量实时数据复核：

1. **月度采样误差**：每月仅取 1 个评估日，会错过精确突破日、放大"追高"误差 → 本次评估日加密到**每个交易日**。
2. **量能条件缺失**：旧缓存无成交量，无法验证原著两大量能条件 → 本次用 xtquant **前复权日线含成交量**，复刻"量能萎缩"与"突破放量确认"。

- **事件**：对每个交易日×标的运行 VCP 检测（窗口 60 日、收缩≥2 次、深度逐次递减、末次≤首次 70%），共检出 **173,614 个 VCP 事件**（其中突破状态 46,442 个）。
- **量能萎缩 `dy`**：末段收缩量能 ≤ 首段收缩量能 × 60%（设计文档默认口径，`VOL_TOL=0.60`）。通过率 **16.7%**。
- **突破放量确认 `bv`**：突破日成交量 ≥ 前 20 日均量 × 1.5。突破事件通过率 **34.6%**。
- **度量**：收盘价突破中枢点当日收盘价成交（≤中枢点 +15% 追高过滤），T+1 起 60 个交易日内先触止损/目标离场；止损 = 中枢点下方 7% 与基底最低点取更近者；同标的两次建仓间隔 ≥ 80 日。
- **参数网格**：止损 7% × RR 2/3 × 收缩 2/3 × RS 0/70/90 × 量能萎缩 0/1 × 突破放量 0/1（要求阶段2、breakout 入场），共 48 组。

## 三、量能维度对比（同参数配对，评估日=交易日）

以（止损7%、RR3、收缩≥3、RS0、要求阶段2）为基准，比较两个量能条件：

| 组合 | 笔数 | 胜率% | 均盈% | 均亏% | 期望% | 中位% | 先+20%% |
|---|---|---|---|---|---|---|---|
| 无量能过滤（dy0 bv0） | 1268 | 32.7 | 25.38 | -10.15 | 1.48 | -7.93 | 36.8 |
| 仅突破放量（bv1） | 882 | 31.9 | 27.05 | -10.52 | 1.45 | -8.23 | 36.6 |
| 仅量能萎缩（dy1） | 195 | 35.4 | 24.84 | -9.92 | **2.38** | -7.59 | 40.5 |
| 两者都要（dy1 bv1） | 137 | 33.6 | 26.68 | -10.20 | 2.18 | -7.77 | 39.4 |

（收缩≥2 同口径：dy0 +0.97% → dy1 +2.69%，先+20% 35.1% → 38.5%）

**结论**
1. **量能萎缩（dy）是有效增强因子**：同参数下期望 +0.9~1.7pp，胜率与"先达 +20%"均提升；代价是交易数缩减约 85%（196/1268）。
2. **突破放量确认（bv）单独无增益**：期望几乎不变（+1.48%→+1.45%），笔数 -30%，且 2020-2022 段反而略降（+1.26%→+0.65%）。**不建议单独作为硬性过滤**；与 dy 叠加时不影响 dy 的增益。
3. 突破事件中仅 34.6% 满足"放量≥1.5×20日均量"，若硬性要求会把样本砍到很小——符合 A 股"缩量突破/次日放量"常见形态，放量确认应看**突破后 2-3 日跟进量**而非单日。

## 四、分段稳健性（关键配置）

| 配置 | 2020-2022 笔数/期望/先+20% | 2023-2026 笔数/期望/先+20% |
|---|---|---|
| mc3 rs0 dy0 bv0（无量能） | 404 / +1.26 / 39.1 | 866 / +1.63 / 35.8 |
| mc3 rs0 **dy1** | 55 / **+4.49** / 56.4 | 140 / **+1.55** / 34.3 |
| mc2 rs0 **dy1** | 105 / +3.80 / 48.6 | 217 / +2.15 / 33.6 |
| mc2 rs90 **dy1** | 50 / +1.51 / 46.0 | 63 / **+7.33** / 44.4 |

**与月度结论的差异**：月度回测显示 2023-2026 期望归零（rr2 转负）；**日度评估 + 量能萎缩过滤后，2023-2026 期望仍为正（+1.6%~+2.2%）**。日度采样捕捉到更精确的突破日，量能萎缩过滤掉了假突破——两者叠加显著改善弱势市表现。

## 六、参数校准结论更新（v2）

| 参数 | v1（月度） | v2（日度+带量） |
|---|---|---|
| 评估/监控频率 | 每月 | **每日**（捕捉精确突破日，笔数×4） |
| 量能萎缩 | 无法验证 | **核心增强条件**：末段 ≤ 首段 60%，期望 +0.9~1.7pp；建议列入 VCP 必选（缺量数据时跳过） |
| 突破放量确认 | 无法验证 | 单日 ≥1.5×20日均量**不单独过滤**；改为突破后 2-3 日累计放量确认 |
| 收缩次数 | ≥3 优先 | ≥3 期望更高，但 **dy1 时 ≥2 亦可（+2.69%）**，样本更大 |
| RS≥90 | 全负期望，不作否决 | **带量萎缩过滤后 rs90 反而居首**（+4.75%，n=113；2023-2026 +7.33%）——高 RS+缩量回调+放量突破是强势股特征，样本小需谨慎 |
| 止损/RR/阶段2 | 7%、RR≥3、保留 | 维持不变 |

**v2 推荐默认（待实盘小仓验证）**
- 每日扫描 VCP；结构条件 + **量能萎缩（末段≤首段60%）**为必选；突破放量不做单日硬过滤。
- 收缩≥2、止损7%、RR≥3、保留阶段2；RS≥90 不再否决，但需量能萎缩同时成立。

- `tools/vcp_detector.py`：`VOL_TOL` 1.15 → **0.60**（对齐设计文档"量能末段<首段60%"）；swing 高低点 numpy 向量化。

## 附录：复现命令

```bash
# 1) 构建带成交量日线缓存（2018-01 ~ 今，前复权，约 1-2 分钟）
python magician_backtest.py cache --start 20180101 --out data/magician/live_cache.pkl

# 2) 日度评估 + 量能扫描（8 进程，检测约 5 分钟 + RS 2 分钟）
python magician_backtest.py sweep --cache data/magician/live_cache.pkl \
    --start 20200101 --end 20260811 --step 1 --stops 7 --rrs 2 3 --mcs 2 3 \
    --rs-min-list 0 70 90 --brv 0 1 --dry 0 1 --workers 8 \
    --out reports/magician-vcp-calibration-daily-20260811.md

# 3) 单配置带量复核
python magician_backtest.py run --cache data/magician/live_cache.pkl \
    --start 20200101 --end 20260811 --step 1 --stop-pct 7 --rr 3 --min-contractions 2 \
    --require-stage2 --require-dry --workers 8
```
