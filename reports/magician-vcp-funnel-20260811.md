# 股票魔法师 VCP 策略基本面漏斗回测（P1）

> 日期：2026-08-11
> 数据：日度带量事件（173,614 个，2020-01~2026-08）× 全市场财务缓存（`finance_indicator/income/pb_weekly/stock_basic`）
> 口径：所有条件按 **ann_date（披露日）point-in-time 对齐**，禁止未来函数；与日度带量复核相同的成交/止损/持有规则
> 工具：`tools/magician_fundamental.py funnel`

---

## 一、结论摘要（先说重点）

1. **基本面漏斗有效，且与量能萎缩正交叠加**：质量红线（F1）→ 营收成长（F2）逐级提升期望。以推荐配置 mc2 rs0 dy1 为例：F0 +2.69% → F1 +3.50% → F2 **+4.28%**；mc3 rs0 dy1 从 +2.38% 升至 **+6.98%**（n=32）。
2. **最贵的一刀是"营收同比 ≥15%"**：通过率仅 28%，但把期望再抬升约 1~2pp；质量红线（F1）通过率 40%，抬升约 1pp。
3. **"营收加速"规则过严（通过率 3%），样本枯竭，建议弃用硬性加速**：F3 仅剩 1-2 笔交易，无法统计。改为"同比 ≥15% 且非大幅回落"的软性观察。
4. **PB 自身分位≤90 过滤效果混杂**（F4 有的配置升有的降），不建议作硬否决。
5. **ROE/现金流是主要质量杀手**：年报 ROE 均值≥8% 通过率仅 58%、现金流/利润中位数≥0.7 通过率 74%——这两条排除了大量"假成长"。

## 二、数据与方法

### 漏斗分级

| 级别 | 内容 | 事件数 | 占全量 |
|---|---|---|---|
| F0 | 全量（日度 VCP，无基本面过滤） | 173,614 | 100% |
| F1 | 质量红线：非ST/未退市 + 负债率≤85% + 现金流/利润中位数≥0.7 + 毛利率≥15% + 年报ROE均值≥8% | 69,482 | 40% |
| F2 | F1 + 营收同比 ≥15%（最新已披露季度 vs 去年同季） | 20,384 | 12% |
| F3 | F2 + 营收加速（最新同比 ≥ 上季同比） | 593 | 0.3% |
| F4 | F2 + PB 自身历史分位 ≤90%（PB 数据 2021 起） | 16,652 | 10% |

### 规则来源

- 质量红线改编自 `quality-screen` 去劣 7 条中可量化部分（负债率≈偿债、现金流/利润≈利润质量、毛利率≈定价权、ROE≈资本效率），因数据只有 2019 起 6-7 年，用"年报 ROE 均值"替代"10 年均值"。
- 成长标准来自 `magician-growth-fundamental`：营收同比 ≥15%（净利润序列缺失，用营收代理，见局限）。
- point-in-time：取事件日之前已披露的最新财报（ann_date ≤ 事件日），同比用去年同季、且同样要求已披露。

## 五、发现与规则修订建议（v4）

| 参数 | v3 规则 | v4 建议 |
|---|---|---|
| 质量红线 | 无 | **新增为必过**：非ST、负债率≤85%、现金流/利润中位数≥0.7、毛利率≥15%、年报ROE均值≥8%（数据缺失不否决） |
| 营收成长 | 无 | **新增为必过**：最新季度营收同比≥15%（point-in-time） |
| 营收加速 | 无 | **弃用硬性加速**（通过率3%样本枯竭）；改为观察项：同比≥15% 且较上季回落 <10pp |
| PB 分位 | 无 | **不作硬否决**；仅当量能萎缩+RS≥90 同时成立时作加分（样本 n=8，谨慎） |
| 漏斗顺序 | 趋势→VCP→量能 | 趋势→**基本面(F1→F2)**→VCP+量能；基本面对 dy0 也有用，建议放在买点层之前 |

## 六、局限

- **净利润缺失**：`finance_income` 只有营收，"净利润加速"无法直接验证，用营收代理；后续可补净利润序列后复测。
- 财务数据 2019 起，早期事件（2020H1）同比口径数据不全（g_rev 通过率可能被低估）。
- ROE 用年报均值替代 10 年均值；未覆盖审计意见、商誉、股本稀释等 quality-screen 其余规则。
- 事件与财报披露日对齐精确到日，但缓存幸存者偏差与成交近似（收盘价、无滑点）与前述报告相同。
- F2/F4 样本已较小（n=17~47），结论为方向性而非精确估计。
