# 股票魔法师 VCP 策略大盘环境分组回测（P0）

> 日期：2026-08-11
> 数据：日度带量事件（173,614 个，2020-01~2026-08）+ 沪深300 日线（`data/magician/index_000300.pkl`）+ 前复权实时缓存
> 规则：沪深300 收盘 vs MA200 定 **up/down**；市场宽度 = 全市场收盘站上自身 MA200 的股票占比（≥60% 为 up_wide）
> 口径：与日度带量复核一致（收盘价成交、T+1、止损=中枢点下方7%/更近基底低点、同标的80日锁仓、60日持有）

---

## 一、结论摘要（先说重点）

1. **简单规则"沪深300 站上 200 日线才交易"在本样本不成立**：带"量能萎缩"过滤的配置里，**down 段（指数跌破 MA200）的期望 ≈ 甚至高于 up 段**。若按 v1 规则在 down 段空仓，会错过样本内表现最好的那批缩量 VCP。
2. **大盘环境不能做"硬开关"，应改做"仓位系数/优先级"**：真正起区分作用的是**个股层面**的量能萎缩 + RS 分位 + 收缩结构，而非指数单一均线。
3. **最强的组合出现在 up_wide（指数站上 MA200 且宽度≥60%）+ 量能萎缩 + RS≥90**：期望 +10.9%（n=38，样本极小，仅作方向提示）。
4. 无量能过滤时，up 段仍略优于 down 段（mc3 rs0 dy0：up +1.91% / down +0.72%）——MA200 规则对"裸 VCP"有弱区分力，但被更强的个股量能过滤取代后就不再有增量。

**逐条解读**
- **dy1（量能萎缩）配置在 down 段不降反升**：down 段笔数少（n=43~84）但胜率与"先达+20%"更高（48-51% vs 34-37%）。弱市里能走出来的 VCP 往往是"缩量到极致 + 机构抢筹"的最强股，恰好是量能萎缩过滤捕捉的形态。
- **裸 VCP（dy0）在 up 段明显更好**（+1.91 vs +0.72）：说明指数均线对"普通突破"有弱择时价值，但对"缩量强突破"无增量。
- **up_wide 只对"双高"配置（dy1+rs90）显著**：+10.93%（n=38）；对 rs0 配置与 dy0 配置无提升甚至略降。宽度作为第二重过滤只对最强信号有效。

## 四、规则修订建议（v3）

| 项目 | v1/v2 规则 | v3 建议 |
|---|---|---|
| 大盘环境 | 沪深300 跌破 MA200 → 空仓 | **删除硬性空仓**；改为**仓位系数**：up_wide ×1.0、up ×0.8、down ×0.5 |
| down 段选股 | 不建新仓 | 保留"量能萎缩 + RS≥70"最强信号，缩小仓位执行；不追裸 VCP |
| 宽度过滤 | 无 | 仅叠加在"量能萎缩 + RS≥90"上（up_wide），作为加仓优先级而非独立开关 |
| 心理模型 | 环境开关 | 环境是"水龙头开度"（仓位），个股三重过滤才是"水压"（信号质量） |

**为什么 v1 结论（活跃市 +3~4%、弱势市 ~0）与本次不一致**：v1 是月度采样 + 无成交量，且按年份粗分；本次按"每个评估日的指数状态"精细分，且加入了量能萎缩。年份不等于环境（2020 与 2024 内部都有强/弱切换），均线状态与个股信号质量的交互更真实。

## 五、局限

- **down 段样本小**（n=43~84），且集中在 2022-2024 的局部反弹窗口，结论需谨慎。
- 指数数据截至 2026-07-31（事件到 08-11），末尾 8 个交易日按前值近似。
- 市场宽度用全缓存股票（含未来上市、含小市值），非 point-in-time 严格口径。
- 未做 regime 滞后 1-3 日、MA200 之外（如 MA50/MA150、新高新低差）的敏感性测试——留作 P0.5。
