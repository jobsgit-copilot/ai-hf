# 股票魔法师 SEPA 入口：漏斗式选股到交易计划卡

对 $ARGUMENTS 执行股票魔法师 SEPA（特定进场点分析）完整流程，用"趋势→基本面→买点→仓位→卖出"五层漏斗逐层筛选，最终输出一张可执行的交易计划卡。

## 适用场景

当你说出：
1. "用股票魔法师方法看看 XX"
2. "哪些股票现在符合 SEPA 买入条件？"
3. "帮我按趋势交易法筛选股票池"
4. "对 XX 建立买入计划"

并且意图是**趋势成长股交易**（而非价值投资长期持有）时，使用本 skill。

与其它 skill 的分工：
- 子流程：`magician-trend-screen`（趋势）→ `magician-growth-fundamental`（基本面）→ `magician-vcp-entry`（买点）→ `magician-risk-position`（仓位）→ `magician-sell-rule`（卖出）
- 复盘：`magician-trade-journal`
- 与价值体系（`quality-screen`、`investment-checklist`、`portfolio-review`）互补：本流程服务交易型资金，价值流程服务长线资金，两者规则不可混用。

---

## 漏斗流程总览

```
第一层：趋势筛选（magician-trend-screen）   趋势模板 8 条 + 第二阶段 + RS≥70
        ↓ 任一硬性否决即排除
第二层：成长基本面（magician-growth-fundamental）  量化硬规则（质量红线+营收同比≥15%，P1校准）+ 催化剂 + 领头羊
        ↓ 否决即排除；存疑需人工复核（可用 tools/magician_fundamental.py funnel 批量回测/筛选）
第三层：VCP 买点（magician-vcp-entry）     收缩递减 + 量能萎缩 + 中枢点
        ↓ 无 VCP 结构 → 进入观察池，不追高
第四层：仓位风控（magician-risk-position） 单笔风险 1.25-2.5%、组合 4-8 只
        ↓ RR<2 或超限 → 放弃
第五层：卖出计划（magician-sell-rule）     止损位 + 盈亏平衡法则 + 晚期警告
        ↓
输出：交易计划卡（含硬性否决记录）
```

每一层被过滤的标的必须留下淘汰理由，不能黑箱。

## 第零步：大盘环境检查（Phase 4/P0 校准）

用指数状态定**仓位系数**，不设硬性空仓开关：

```bash
python3 tools/magician_data.py trend 000300.SH --json   # 沪深300 趋势与阶段
```

- 沪深300 站上 200 日均线 且 市场宽度（全市场站上 MA200 的股票占比）≥ 60% → 仓位系数 1.0（正常执行漏斗）。
- 仅站上 MA200（宽度 <60%）→ 系数 0.8。
- 跌破 MA200 → 系数 0.5；只保留"量能萎缩 + RS≥70"的最强信号，不追裸 VCP。
- 依据（P0 分组回测，`reports/magician-vcp-regime-20260811.md`）：指数 MA200 对裸 VCP 有弱区分力（up +1.91% vs down +0.72%），但对"量能萎缩"过滤后的强信号无增量（down 段期望反而 ≥ up 段，样本小）；最强组合在 up_wide+量能萎缩+RS≥90（+10.9%，n=38）。故环境作为仓位/优先级调节，个股三重过滤才是主判据。

## 参数校准（P2 组合级回测，2026-08-12）

`tools/magician_portfolio.py` 组合模拟（1601 交易日）确认 v5 参数：

| 参数 | 建议 |
|---|---|
| 基本面漏斗 | F1 质量红线必过（ST/负债率≤85%/现金流利润比≥0.7/毛利率≥15%/ROE≥8%） |
| 量能萎缩 | **分级（v6）**：末段≤首段60% 全仓；未达标半仓（`--nody-half`） |
| 收缩次数 | ≥3（组合层最优；≥2 追求交易频率） |
| 止损 / 盈亏比 | 7% / RR≥3 |
| 仓位 | 单笔风险 1.0-1.5%；最多 6 仓 |
| 同日多信号 | **RS 降序优先入场（v7，领头羊优先）**：`--rs-priority`，全样本 C/D 0.55→0.86 |
| 大盘环境 | 可选系数（up_wide×1.0/up×0.8/down×0.5） |

样本外验证（2026-08-12）：训练窗 2020-2023 第二梯队 8 个放宽变体无一超过 v6（C/D 0.33）；随后 **RS 优先入场（v7）被采纳**——全样本 C/D 0.55→0.86、测试窗 1.62→2.16，0.5% 摩擦后仍 0.71。测试窗 2024-2026 v6 CAGR 16.1%、回撤 -10.1%、C/D 1.60，7 年中 6 年正——未过拟合。risk2.0+单只30% 为进取版（CAGR 18.4%/回撤 -13.2%/C/D 1.39），默认不启用。

样本内 v5（F1+量能萎缩必选+收缩≥3）：CAGR 9.0%、最大回撤 -18.9%、累计 +73% vs 沪深300 +10.5%。v6（量能分级：非 dy 半仓）CAGR 10.0%、回撤 -18.2%、C/D 0.55；**v7（+RS 优先入场）为当前推荐**：CAGR 14.6%、回撤 -17.1%、C/D 0.86（0.5% 摩擦后 12.6%/C/D 0.71）。注意暴露仅 35%——现金拖累显著，实盘需打折。

## 第一步：确认标的池与约束

先明确：
- 标的池：单个代码 / 代码列表 / 行业或主题（先展开成分股）/ 自选股池文件
- 账户约束：总资金、可用资金、现有持仓（成本与数量）
- 数据规则：A 股默认 T+1；跌停/涨停需预案；ST 与退市风险股直接排除

工具入口（数据统一走股票魔法师工具）：
- 行情与趋势：`python3 tools/magician_data.py trend 代码 [--json]`
- 相对强度：`python3 tools/magician_data.py rs 代码`
- VCP：`python3 tools/vcp_detector.py detect 代码` / `scan 代码1 代码2 ...`
- 财务：`python3 tools/ashare_data.py financials 代码`

## 第二步至第五步：调用子 skill

按顺序调用（各子 skill 内已包含完整判定规则）：

1. `magician-trend-screen`：得到第二阶段候选池（模板 8 条逐项 + RS）。
2. `magician-growth-fundamental`：对候选池逐个出"通过/存疑/否决"。
3. `magician-vcp-entry`：对通过者检测 VCP，输出买点/止损/目标。
4. `magician-risk-position`：计算每只的仓位与组合约束。
5. `magician-sell-rule`：预先写好转强/转弱的卖出预案。

## 硬性否决清单（任一命中即终止该标的，不再进入下一层）

| # | 否决项 | 说明 |
|---|--------|------|
| 1 | 非第二阶段 | 阶段判定为 stage1/3/4 |
| 2 | 趋势模板通过数 < 8 | 有豁免需逐条记录理由 |
| 3 | RS < 70 | 相对强度不足（A 股可放宽至 ≥ 70 分位，低于则否决） |
| 4 | 基本面否决 | 财报爆雷 / ST / 退市风险 |
| 5 | 无 VCP 结构 | 不得追高买入，只进观察池 |
| 6 | RR < 2:1 | 目标空间不足止损的两倍 |
| 7 | 止损 > 10% | 单笔止损超过 10% 放弃 |
| 8 | 组合超限 | 持仓 > 8 只 或 同板块 > 2 只且无换出对象 |

## 输出：交易计划卡

每只通过标的输出一张计划卡：

```text
标的：______  代码：______  日期：______
1. 趋势：第二阶段 [ ]  模板 [8/8]  缺口项：______  RS：______
2. 基本面：通过 [ ] / 存疑 [ ] / 否决 [ ]   依据：______
3. VCP：足迹 ______  中枢点 ______  买点 ______  状态：等待 [ ] / 突破 [ ] / 形成中 [ ]
4. 止损价：______（中枢点下方 7-10% 或基底低点，取高者）
5. 目标价：______（RR ≥ 2）
6. 仓位：资金 ______  单笔风险 __%  股数 ______  占比 __%
7. 卖出预案：弱势 ______ / 强势 ______ / 晚期警告 ______
8. 否决检查：无 [ ]   备注 ______
```

同时输出"观察池"（暂不满足但接近条件的标的及其待触发条件）。

## 纪律要求

- 任一硬性否决不因"感觉不错"而豁免；豁免必须书面记录。
- 未形成交易计划卡之前不下单。
- 计划卡写入交易日志（`magician-trade-journal`），后续按 `magician-sell-rule` 跟踪。
