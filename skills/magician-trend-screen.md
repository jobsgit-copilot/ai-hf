# 趋势模板筛选：第二阶段候选池

对 $ARGUMENTS 执行股票魔法师"趋势模板 8 条 + 四阶段 + 相对强度"筛选，输出第二阶段候选池。

## 适用场景

- 给定一批股票代码，判断哪些处于第二阶段上升趋势
- 全市场/行业/主题候选池的趋势初筛
- 为 `magician-sepa` 漏斗提供第一层输入

与其它 skill 的关系：
- 输出给 `magician-growth-fundamental`（基本面确认）与 `magician-vcp-entry`（买点）
- 单看趋势不看基本面与买点，避免越权

---

## 第一步：拉取行情与计算

对每个标的运行（数据源：ai2miniqmt xtquant 前复权日线 + 全市场缓存 RS）：

```bash
python3 tools/magician_data.py trend 600519 --json      # 趋势模板 8 条 + 阶段 + 结论
python3 tools/magician_data.py rs 600519                 # RS 分位（63/126/252 日）
python3 tools/magician_data.py bars 600519 --days 420    # 日线明细（需要时）
```

`trend` 输出已包含逐条判定、阶段与结论（pass/watch/fail），直接作为筛选依据。

## 第二步：趋势模板 8 条（逐条判定）

| # | 规则 | 说明（数值取自《纵横天下股市的奥秘》b1_ch5） |
|---|------|------|
| 1 | 收盘价 > 150 日均线 | 用前复权价计算 |
| 2 | 收盘价 > 200 日均线 | |
| 3 | 200 日均线上行 ≥ 1 个月 | 对比 20 个交易日前 |
| 4 | 50 日均线 > 150 日均线 > 200 日均线 | 均线多头排列 |
| 5 | 收盘价 > 50 日均线 | 短期强势 |
| 6 | 距 52 周低点 ≥ 25% | 脱离底部 |
| 7 | 距 52 周高点 ≤ 25% | 接近新高（越近越好） |
| 8 | 相对强度 RS ≥ 70 | 全市场分位，最好 ≥ 90 |

## 第三步：四阶段判定

工具输出 stage1-4；只允许**第二阶段**进入候选池：

| 阶段 | 含义 | 处理 |
|------|------|------|
| 第一阶段 | 筑底/忽略 | 不入池，可观察 |
| 第二阶段 | 上升/唯一可买 | 入池 |
| 第三阶段 | 派发/危险 | 排除 |
| 第四阶段 | 下跌/禁止 | 排除 |

> 说明：阶段为启发式判定，供人工复核；若模板通过数与阶段结论矛盾（如 8 条全过但判为 stage1），以模板为准并记录。

## 第四步：RS 排序

- 主 RS 取 252 日分位（上市不足则用 126 日），全市场横截面 0-99。
- 候选池按 RS 降序排列；RS ≥ 70 为加分项，优先研究板块领头羊。
- 校准提示（Phase 4）：月度回测显示 RS≥90 硬过滤负期望（高 RS 常处行情后段），**不作为一票否决**；日度+带量复核显示，RS≥90 仅在与**量能萎缩**同时成立时为正（样本小），单独追高 RS 仍需警惕尾声。
- 组合层校准（v7，2026-08-12）：同日多信号按 **RS 降序优先入场**（`--rs-priority`，领头羊优先），全样本 C/D 0.55→0.86、测试窗 1.62→2.16，0.5% 摩擦后仍 0.71——RS 的用途是**排序优先**而非否决。
- A 股适配：RS 基于全市场 5000+ 只横截面，缓存截至日为 T-1 级别，使用时标注数据日期。

## 输出候选池

表格（含每项明细，可追溯）：

```text
代码       名称   阶段   模板通过数  RS   收盘vs50/150/200   距低点  距高点
600519.SH  ...   stage2  8/8        92    +2%/+1%/+0%       +35%    -8%
```

同时输出"观察池"：模板 5-7 条通过但未达 8 条、或阶段尚在转换中的标的，注明缺口。

## 硬性否决

- 阶段非 stage2 → 排除（除非明确豁免并记录）
- 模板通过数 < 8 → 排除
- ST / 退市风险 / 长期停牌 → 排除
- RS < 70 → 不作硬性否决（校准后为加分项；报告中注明 RS 值即可）
